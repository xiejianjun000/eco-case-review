## 🚀 启动完整 Vue 项目

### 前置要求
- Node.js 16+ 和 npm
- 或者使用 PNPM / Yarn

### 安装依赖

#### Windows 用户（推荐）
```cmd
cd frontend
call install.bat
```

#### 或者手动安装
```cmd
cd frontend
npm install
npm run dev
```

### 访问地址
开发服务器启动后，访问：`http://localhost:5173`
