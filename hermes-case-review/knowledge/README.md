## 快速下载

### 方式一：点击链接下载（推荐）

1. 点击上方链接
2. 在WPS页面点击"下载"按钮
3. 保存到本地后上传到项目目录

### 方式二：命令行下载

```bash
# 下载到项目目录
cd /workspace/hermes-case-review/knowledge

# 评查细则
wget -O "评查细则/生态环境行政执法案卷评查细则（2024年版）.pdf" "[链接]"

# 法律法规
wget -O "法律法规/生态环境保护法律法规汇编（2026.5）.pdf" "[链接]"

# 复函汇编

# 部长信箱
wget -O "部长信箱/生态环境部部长信箱回复汇编（2026.1）.pdf" "[链接]"
```
