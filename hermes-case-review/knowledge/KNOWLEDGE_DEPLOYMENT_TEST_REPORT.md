## 六、系统集成说明

### 6.1 文件路径

所有文件位于: `/workspace/hermes-case-review/knowledge/`

### 6.2 索引访问

```python
import json

with open('knowledge/knowledge_index.json', 'r') as f:
    kb_index = json.load(f)

# 访问文档列表
for doc in kb_index['documents']:
    print(f"{doc['title']} - {doc['path']}")
```

### 6.3 知识检索接口

```python
def search_knowledge(query: str):
    """搜索知识库"""
    results = []
    for doc in kb_index['documents']:
        if query in doc['title']:
            results.append(doc)
    return results
```
