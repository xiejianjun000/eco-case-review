# 智能体记忆配置模板

## 概述

**记忆（Memory）** 是智能体的经验库，存储历史案例、用户偏好、学习成果等，使智能体能够基于过去的经验做出更准确的分析。

---

```markdown

# 裁量计算师 - 记忆库

### 裁量类型分布
| 违法类型 | 案件数 | 平均罚款(万) | 合理区间 |
|----------|--------|--------------|----------|
| 大气污染 | 234 | 45.6 | 20-100 |
| 水污染 | 156 | 68.3 | 30-200 |
| 固废污染 | 123 | 38.2 | 15-80 |
| 噪声污染 | 54 | 12.5 | 5-30 |

## 学习记录

### 好评记录
```json
{
  "total_praise": 551,
  "records": [
    {
      "date": "2024-05-15",
      "case_id": "case-2024-045",
      "reason": "准确计算超标倍数",
      "user_feedback": "计算过程清晰，依据充分"
    }
  ]
}
```

## 知识沉淀

### 裁量基准公式
```
实际罚款 = 法定最低 + (法定最高 - 法定最低) × 裁量系数
```

### 常见裁量因素
1. 超标倍数 → 基础裁量
2. 改正情况 → 加减项
3. 主观过错 → 加减项
4. 危害后果 → 加减项
5. 配合程度 → 加减项
```

## 记忆更新机制

### 好评处理流程
```
用户点击👍 
  ↓
记录好评到历史库
  ↓
提取好评原因
  ↓
更新最佳实践库
  ↓
优化分析策略
```

### 差评处理流程
```
用户点击👎
  ↓
记录差评到历史库
  ↓
分析问题原因
  ↓
生成改进建议
  ↓
更新知识库
  ↓
标记需优化项
```
