# 智能体技能配置模板

## 概述

**技能（Skills）** 是智能体执行具体任务的能力集合，定义了智能体可以完成的工作类型、输入输出格式和执行步骤。

### 1. 合法性审查员技能

```markdown
# 合法性审查员 - 技能配置

## 基本信息

**技能名称**: legality_review
**版本**: v2.1
**功能**: 25项一票否决条件检查

## 技能描述

### 核心功能
检查生态环境行政处罚案卷是否触发25项一票否决条件，包括执法主体、违法主体、违法事实证据、法律适用、执法程序五大领域。

### 适用场景
1. 行政处罚案卷合法性审查
2. 执法程序合规性检查
3. 法律适用准确性验证

## 输入定义

### 必需输入
| 字段名 | 类型 | 描述 | 示例 |
|--------|------|------|------|
| case_content | string | 案卷文本内容 | "案卷完整文本..." |
| case_type | string | 案件类型 | "一般行政处罚" |

### 可选输入
| 字段名 | 类型 | 描述 | 默认值 |
|--------|------|------|--------|
| check_items | array | 指定检查项 | 全部25项 |

## 输出定义

```json
{
  "success": true,
  "result": {
    "has_veto": false,
    "legality_score": 50,
    "legality_pass": true,
    "veto_items": [
      {
        "number": 14,
        "category": "执法程序",
        "description": "未告知程序性权利",
        "evidence_page": "第15页",
        "legal_basis": "《行政处罚法》第44条"
      }
    ],
    "findings": []
  }
}
```

## 执行流程

### 步骤1: 解析案卷
提取案卷文本，识别关键要素

### 步骤2: 逐项检查
按25项否决条件逐一检查

### 步骤3: 汇总结果
统计否决项，生成报告

## 25项否决条件清单

### 执法主体（2项）
- 序号1: 实施机关职权
- 序号2: 执法人员资格

### 违法主体（3项）
- 序号3-5: 主体相关问题

### 违法事实证据（2项）
- 序号6-7: 证据相关问题

### 法律适用（6项）
- 序号8-13: 法律适用问题

### 执法程序（12项）
- 序号14-25: 程序相关问题
```

### 2. 裁量计算师技能

```markdown
# 裁量计算师 - 技能配置

## 基本信息

**技能名称**: discretion_calculation
**版本**: v1.5
**功能**: 罚款金额裁量计算与合理性评估

## 技能描述

### 核心功能
根据违法类型和裁量因素，自动计算罚款金额，评估合理性。

### 适用场景
1. 罚款金额计算验证
2. 裁量基准适用检查
3. 处罚合理性评估

## 输入定义

| 字段名 | 类型 | 描述 | 示例 |
|--------|------|------|------|
| violation_type | string | 违法类型 | "大气污染" |
| case_data | object | 案件数据 | {...} |

### case_data 结构
```json
{
  "超标倍数": "2.5",
  "改正情况": "限期改正",
  "主观过错": "过失",
  "影响范围": "一般",
  "配合程度": "积极配合",
  "recorded_fine": 50
}
```

## 输出定义

```json
{
  "success": true,
  "result": {
    "applicable": true,
    "table_used": "大气污染裁量表",
    "legal_range": "10-100万元",
    "factors": [
      {
        "factor_name": "超标倍数",
        "case_value": "2.5",
        "percentage": 0.4
      }
    ],
    "total_percentage": 0.5,
    "calculated_fine": 55.0,
    "recorded_fine": 50.0,
    "fine_difference": -5.0,
    "reasonableness": "基本合理"
  }
}
```

## 裁量因素

### 大气污染
1. 超标倍数 → 10%-100%
2. 改正情况 → -10% to +20%
3. 主观过错 → -15% to +20%
4. 影响范围 → -10% to +30%
5. 配合程度 → -10% to +15%

### 水污染
1. 超标倍数 → 10%-100%
2. 改正情况 → -10% to +20%
3. 主观过错 → -15% to +20%
4. 影响范围 → -10% to +30%
5. 配合程度 → -10% to +15%

### 固废污染
1. 数量规模 → 15%-100%
2. 改正情况 → -10% to +20%
3. 危害后果 → -10% to +30%

### 噪声污染
1. 超标分贝 → 20%-100%
2. 持续时间 → 30%-100%

## 计算公式

```
裁量百分值 = 基础值(30%) + Σ各因素百分值

实际罚款 = 法定最低 + (法定最高 - 法定最低) × 裁量百分值
```
