# V4 行政处罚案卷评查系统 - 生产部署检查清单

## 部署前检查

### 代码与镜像
- [ ] 代码安全扫描通过（Trivy / Snyk）
- [ ] 镜像漏洞扫描通过（Trivy 高危为 0）
- [ ] 单元测试全部通过
- [ ] 集成测试全部通过
- [ ] 镜像大小确认 < 500MB
- [ ] 镜像 Tag 与版本号一致

### 配置参数
- [ ] ConfigMap 中的环境变量已确认
- [ ] Secret 中的敏感信息已替换（非占位符）
- [ ] OCR_ENGINE 配置正确（local / cloud / azure）
- [ ] MAX_PDF_SIZE 和 MAX_PAGES 符合业务需求
- [ ] LOG_LEVEL 设置正确（生产建议 INFO 或 WARNING）
- [ ] TLS 证书有效且未过期
- [ ] 域名 DNS 解析正确

### 数据与备份
- [ ] 数据库备份已完成
- [ ] 备份数据可恢复性已验证
- [ ] 当前版本镜像已标记备份 Tag
- [ ] PVC 快照已创建（Kubernetes 环境）
- [ ] 回滚方案已准备并测试

### 基础设施
- [ ] 目标集群资源充足（CPU / 内存 / 存储）
- [ ] 网络策略配置正确
- [ ] PersistentVolume 可用
- [ ] Ingress Controller 已部署
- [ ] 证书管理器（cert-manager）已配置
- [ ] 监控系统（Prometheus + Grafana）已就绪
