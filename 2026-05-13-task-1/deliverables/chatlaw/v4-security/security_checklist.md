# V4行政处罚案卷评查系统 - 安全配置检查清单

## 一、身份认证

### 1.1 JWT Token配置
- [ ] Token过期时间设置为 `< 24小时` (建议: 2小时)
- [ ] Refresh Token过期时间设置 `< 7天`
- [ ] Token签名使用HS256或RS256算法
- [ ] Token中不包含敏感信息
- [ ] 实现Token黑名单机制

```python
# JWT配置示例
JWT_CONFIG = {
    "ACCESS_TOKEN_EXPIRE_MINUTES": 120,  # 2小时
    "REFRESH_TOKEN_EXPIRE_DAYS": 7,
    "ALGORITHM": "HS256",
    "BLACKLIST_ENABLED": True,
}
```

### 1.2 密码策略
- [ ] 最小密码长度 `>= 8位`
- [ ] 必须包含大写字母
- [ ] 必须包含小写字母
- [ ] 必须包含数字
- [ ] 必须包含特殊字符
- [ ] 禁止使用常见弱密码
- [ ] 密码不允许与用户名相同

### 1.3 登录安全
- [ ] 登录失败锁定: `5次失败 / 30分钟锁定`
- [ ] 锁定时间: `>= 30分钟` 或管理员解锁
- [ ] 登录IP限制 (可选)
- [ ] 异地登录告警 (可选)
- [ ] 登录成功发送通知 (可选)

## 二、数据安全

### 2.1 传输安全
- [ ] 全站HTTPS强制 (HTTP自动跳转HTTPS)
- [ ] TLS版本 >= 1.2
- [ ] 禁用SSLv2、SSLv3、TLS 1.0、TLS 1.1
- [ ] 使用安全密码套件
- [ ] HSTS头配置 (`max-age >= 31536000`)
- [ ] 证书配置正确 (无自签名证书在生产环境)

### 2.2 敏感数据保护
- [ ] 敏感字段脱敏处理已启用
- [ ] 脱敏规则配置正确
- [ ] 数据库加密存储已启用
- [ ] 备份加密已配置
- [ ] 敏感日志已脱敏
- [ ] API响应中无敏感信息泄露

### 2.3 数据加密
- [ ] 数据库连接使用SSL/TLS
- [ ] 敏感字段(如密码)使用强哈希算法 (bcrypt/argon2)
- [ ] 重要数据加密存储 (Fernet/AES)
- [ ] 加密密钥管理规范

---

## 三、接口安全

### 3.1 API限流
- [ ] 全局限流已配置
- [ ] 普通用户限流: `100次/分钟`
- [ ] 评查员限流: `500次/分钟`
- [ ] 管理员限流: `1000次/分钟`
- [ ] 未认证用户限流: `20次/分钟`
- [ ] 限流响应头正确返回

### 3.2 CORS配置
- [ ] 仅允许信任域名
- [ ] 禁止 `Access-Control-Allow-Origin: *` (生产环境)
- [ ] 仅允许必要的HTTP方法
- [ ] 仅允许必要的请求头
- [ ] 凭证请求配置正确

### 3.3 输入验证
- [ ] 文件名特殊字符过滤
- [ ] SQL注入防护 (参数化查询)
- [ ] XSS防护 (输入转义)
- [ ] 命令注入防护
- [ ] JSON Schema验证
- [ ] 请求体大小限制

### 3.4 响应安全头
- [ ] Content-Security-Policy配置
- [ ] X-Content-Type-Options: nosniff
- [ ] X-Frame-Options: DENY或SAMEORIGIN
- [ ] X-XSS-Protection: 1; mode=block
- [ ] Referrer-Policy配置
