### 2.2 核心法规解读：《案卷评查细则（2024年版）》

#### 评分计算公式
```
案卷得分 = 合法性评查得分(50) + 规范性评查得分
规范性评查得分 = 50 × (对应评查项目得分之和 / 参与评查项目标准分之和) - 基本要素扣分值之和
```

#### ⚠️ 关键规则：一票否决制
> **案卷评查存在任一项重大问题的，直接评为0分**

## 4. 裁量权基准（来自周法官 · 法条研究员）

### 4.1 湖南省裁量基准（2021版）核心要点

#### 裁量计算公式
```
罚款金额 = 裁量百分值总和 × 法定最高罚款数额（或倍数）
```

#### 裁量因素（6项）
1. **环境污染、生态破坏程度及社会影响**
2. **当事人主观过错程度**
3. **违法行为具体方式或手段**
4. **违法行为危害的具体对象**
5. **环境违法行为次数**（两年内）
6. **当事人改正态度和措施**

#### 从重/从轻/减轻/不予处罚情形

| 情形 | 条件 | 裁量规则 |
|------|------|---------|
| **从重** | 拒不配合调查、重大污染、媒体曝光、重污染天气顶风作案等 | 可增加不超过法定最高罚款20% |
| **从轻** | 主动消除危害后果、受胁迫、主动供述、立功表现 | 可减少不超过法定最高罚款20% |
| **减轻** | 符合减轻条件 | 可减少不超过法定最低罚款50% |
| **不予处罚** | 轻微且及时改正、主客观无过错、法律规定情形 | 应当不予处罚，但需教育 |

### 4.2 专用裁量表（部分示例）

### 5.3 评分算法建议

```python
# 评查得分计算算法
def calculate_case_score(case_data):
    # 1. 合法性评查（50分，一票否决）
    legality_issues = check_legality_issues(case_data)  # 25项检查
    if legality_issues.has_critical_issues():
        return 0  # 一票否决，得0分
    
    legality_score = 50  # 通过得50分
    
    # 2. 规范性评查
    # 2.1 卷面基本要素（20分，扣分制）
    basic_deductions = check_basic_elements(case_data)  # 扣分项
    basic_score = 20 - basic_deductions
    
    # 2.2 各类型文书（按比例计算）
    document_scores = calculate_document_scores(case_data)  # 各文书得分
    document_max = get_document_max_scores(case_data.type)  # 最大分值
    document_ratio = document_scores / document_max
    
    normative_score = 50 * document_ratio - basic_deductions
    
    # 3. 总分
    total_score = legality_score + normative_score
    
    return {
        'total_score': total_score,
        'legality_score': legality_score,
        'basic_elements_score': basic_score,
        'document_score': normative_score,
        'issues': legality_issues + basic_deductions
    }
```
