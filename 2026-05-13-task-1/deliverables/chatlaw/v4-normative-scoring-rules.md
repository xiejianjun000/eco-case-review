# 第一章 规范性评查总则

## 1.1 评查范围与分值体系

### 1.1.1 评查对象范围

本规则适用于湖南省行政区域内生态环境行政处罚案卷的规范性评查工作，涵盖以下六类案件类型：

1. **一般行政处罚案件**：适用普通程序实施的生态环境行政处罚案件
2. **不予行政处罚案件**：依据《行政处罚法》第三十三条等规定依法不予处罚的案件
3. **按日连续处罚案件**：依据《环境保护法》第五十九条等规定实施的按日连续处罚案件
4. **查封/扣押案件**：依据《行政强制法》《环境保护主管部门实施查封、扣押办法》实施的行政强制案件
5. **移送拘留案件**：依据《环境保护法》第六十三条等规定移送公安机关行政拘留的案件
6. **移送涉嫌环境污染犯罪案件**：依据《刑法》第三百三十八条及相关司法解释移送司法机关追究刑事责任的案件

### 1.1.2 分值体系总览

根据《生态环境行政执法案卷评查细则（2024年版）》（以下简称"评查细则"）的规定，案卷评查分为"合法性评查"和"规范性评查"两个部分，总分100分。具体分值构成如下表所示：

| 评查类别 | 评查方式 | 基础分值 | 说明 |
|----------|----------|----------|------|
| **合法性评查** | 一票否决制 | 50分 | 存在重大问题直接评为0分 |
| **规范性评查** | 比例换算+扣分 | 50分 | 含卷面基本要素和各类型文书 |
| **案卷总分** | — | 100分 | 合法性50+规范性50 |

### 1.1.3 各类型案件规范性评查分值配置

不同案件类型的文书配置存在差异，具体分值配置如下：

| 案件类型 | 规范性问题满分 | 备注 |
|----------|-----------------|------|
| 一般行政处罚 | 100分 | 14项文书 |
| 不予行政处罚 | 100分 | 12项文书 |
| 按日连续处罚 | 120分 | 16项文书（增加2项） |
| 查封/扣押 | 100分 | 9项文书 |
| 移送拘留 | 100分+15分加分 | 11项文书+1项加分 |
| 移送涉嫌环境污染犯罪 | 100分+15分加分 | 8项文书+1项加分 |

## 1.2 评查方法

### 1.2.1 评查方式分类

规范性评查采用两种不同的评查方法，分别适用于不同的评查项目：

#### （一）扣分制——卷面基本要素评查项

**适用范围**：所有案件类型的通用文书基本要素检查

**操作方式**：任一文书存在缺少基本要素情形的，均扣除该要素对应的分数，扣完为止。

**分值配置**：共20分，其中：
- 各类文书基本要素：10分
- 现场检查（勘察）笔录/调查询问笔录基本要素：10分

**法规依据**：《评查细则》第二部分第一章（"二（一）"）

#### （二）得分制——各类型文书评查项

**适用范围**：根据案件类型确定的具体文书评查

**操作方式**：对照评分细则逐项打分，采用得分制。

**评分原则**：
1. 文书中不涉及的要素不需评查
2. 根据案情无需该文书的，该项文书整体无需评审
3. 无特定文书的，该项得0分

**法规依据**：《评查细则》第二部分第二章（"二（二）"）

### 1.2.2 评查操作流程

```
┌─────────────────────────────────────────────────────────────┐
│                    规范性评查操作流程                         │
├─────────────────────────────────────────────────────────────┤
│  Step 1: 识别案件类型                                        │
│          ↓                                                    │
│  Step 2: 进行卷面基本要素评查（扣分制，满分20分）             │
│          ↓                                                    │
│  Step 3: 确定参与评查的文书类型                               │
│          ↓                                                    │
│  Step 4: 对各类型文书逐项评分（得分制）                       │
│          ↓                                                    │
│  Step 5: 计算规范性评查得分                                   │
│          ↓                                                    │
│  Step 6: 汇总合法性评查+规范性评查得出总分                    │
└─────────────────────────────────────────────────────────────┘
```

## 1.3 分值计算公式详解

### 1.3.1 核心计算公式

根据《评查细则》的规定，案卷得分采用以下公式计算：

```
案卷得分 = 合法性评查得分（50）+ 规范性评查得分（50）
```

其中，规范性评查得分的计算公式为：

```
规范性评查得分 = 50 × (参与评查项目得分之和 ÷ 参与评查项目标准分之和) - 基本要素扣分值之和
```

### 1.3.2 比例系数换算详解

**比例系数**是指"参与评查项目得分之和"与"参与评查项目标准分之和"的比值，其含义是：

| 比例系数含义 | 说明 |
|--------------|------|
| 概念 | 文书实际得分占应得满分的比例 |
| 取值范围 | 0% ≤ 比例系数 ≤ 100% |
| 计算方式 | 比例系数 = 实际得分 ÷ 标准总分 × 100% |

### 1.3.3 计算示例

**示例一：一般行政处罚案件**

某一般行政处罚案件，各类型文书实际得分85分（满分100分），卷面基本要素无扣分。

```
比例系数 = 85 ÷ 100 = 0.85

规范性评查得分 = 50 × 0.85 - 0 = 42.5分

案卷总分 = 50 + 42.5 = 92.5分
```

**示例二：存在基本要素扣分的情况**

某一般行政处罚案件，各类型文书实际得分80分（满分100分），卷面基本要素扣3分。

```
比例系数 = 80 ÷ 100 = 0.80

规范性评查得分 = 50 × 0.80 - 3 = 40 - 3 = 37分

案卷总分 = 50 + 37 = 87分
```

**示例三：按日连续处罚案件**

某按日连续处罚案件，各类型文书实际得分100分（满分120分），卷面基本要素扣2分。

```
比例系数 = 100 ÷ 120 ≈ 0.833

规范性评查得分 = 50 × 0.833 - 2 ≈ 41.67 - 2 = 39.67分

案卷总分 = 50 + 39.67 = 89.67分
```

### 1.3.4 公式应用注意事项

1. **参与评查项目的确定**：根据案情不需要的文书，不纳入参与评查项目
2. **基本要素扣分**：独立于比例系数计算，直接从规范性评查得分中扣除
3. **最高分值限制**：规范性评查得分最高为50分（比例系数100%且无扣分时）
4. **一票否决优先**：若存在重大问题，案卷直接评为0分，无需计算规范性评查得分

# 第二章 卷面基本要素评查项（含双引用）

## 2.1 评查项概述

根据《评查细则》二（一）的规定，卷面基本要素评查项共20分，采用扣分制。评查时，任一文书存在缺少以下基本要素情形的，均扣除该要素对应的分数。

**评查方式说明**：
1. 结合文书实际情况，确定需评查的基本要素
2. 文书中不涉及的要素不需评查
3. 各类型文书评查项中已经明确列明评查的事项，不在此项中扣分

### 2.2.2 评查要点说明

**【评查细则】二（一）1-5 详解**

本检查项对应《评查细则》二（一）第1-5项，涵盖各类文书的通用基本要素。评查时应注意：

1. **要素完整性检查**：按照上述五项要素逐一核对，确保不缺项
2. **文书关联性**：同一案卷中不同文书的基本要素应相互印证
3. **常见错误防范**：重点关注上表"常见错误"栏所列问题，防止同类问题重复发生

### 2.3.2 评查要点说明

**【评查细则】二（一）6-14 详解**

本检查项对应《评查细则》二（一）第6-14项，专门针对现场检查（勘察）笔录和调查询问笔录的基本要素。评查时应注意：

1. **时间地点精确性**：检查/询问的时间应精确到分钟，地点应具体明确
2. **身份核验完整性**：执法人员信息应包含执法证号，被检查人信息应包含身份证明
3. **权利告知规范性**：必须明确告知当事人申请回避、陈述申辩等权利
4. **签名确认完整性**：包括逐页签名、末页审阅确认、修改处签名或压指印等
5. **空白处理规范性**：空白处应注明"以下空白"或划有斜线，防止事后添加内容

### 3.1.2 重点文书评查要点

#### （1）行政处罚决定书（15分）——最高权重文书

**【评查细则】二（二）1.11 详解**

本项为一般行政处罚文书评查中分值最高的文书（15分），评查要点包括：

1. **违法事实认定（3分）**
   - 时间、地点、行为、情节、动机、后果是否完整
   - 与证据材料是否对应

2. **主要证据（3分）**
   - 证据名称、提取时间、提供单位、证明内容是否清晰
   - 不同证据之间是否形成证据链

3. **法律依据（2分）**
   - 违反的法律、法规、规章条款是否准确
   - 作出处罚的法律依据是否正确

4. **陈述申辩听证过程（2分）**
   - 当事人意见理由及证据是否记录
   - 生态环境主管部门采纳情况及理由

5. **裁量基准（1分）**
   - 选定的裁量因素是否有依据
   - 从重、从轻、减轻裁量是否有说明理由

6. **处罚内容（1分）**
   - 种类、幅度是否在法定范围内

7. **履行信息（0.5分）**
   - 履行方式、期限是否明确

8. **救济途径（1分）**
   - 不服决定的救济途径和期限是否正确

9. **法律后果（0.5分）**
   - 不履行的法律后果是否告知

10. **期限合规（1分）**
    - 是否在法定期限内作出（听证、公告、监测、鉴定、送达时间不计入）

### 3.2.2 不予行政处罚决定书特别评查要点（20分）

本项为按日连续处罚案件的特有文书，评查要点：

6. **告知拒不改正的按日连续处罚后果（0.5分）**：是否明确告知

2. **初次检查的证据信息（1分）**：证据名称、提取时间、提供单位、证明内容
3. **初次检查发现的违法行为违反的法律依据（1分）**：具体条款
4. **责令改正决定书信息（1分）**：决定书文号、送达情况

8. **复查中拒不改正的证据信息（1分）**：证据名称、提取时间、提供单位、证明内容

## 4.2 裁量因素完整性检查

### 4.2.1 裁量因素体系

根据《裁量基准规定》第六条的规定，裁量因素包括以下六个方面：

| 序号 | 裁量因素类别 | 具体内容 | 裁量因子考量方向 |
|------|--------------|----------|-----------------|
| 1 | 环境污染、生态破坏程度及社会影响 | 违法行为所造成的后果严重程度 | 危害后果、影响范围、持续时间 |
| 2 | 主观过错程度 | 当事人的主观故意或过失 | 故意、过失、无过错 |
| 3 | 违法行为的具体方式或手段 | 违法行为的表现形式 | 主动实施、被动实施、胁迫实施 |
| 4 | 违法行为的危害对象 | 违法行为针对的具体对象 | 人群、水体、大气、土壤等 |
| 5 | 环境违法次数 | 当事人违法行为的频次 | 初次、再次、多次 |
| 6 | 改正态度和效果 | 当事人改正违法行为的态度和措施 | 积极改正、消极应付、拒绝改正 |

### 4.2.2 裁量因素完整性检查要点

评查时应逐一核对以下内容：

1. **裁量因素选取是否完整**
   - 对照裁量表列明的裁量因素，逐一核查是否全部选取
   - 如某裁量因素不适用于本案，应在案卷中说明理由

2. **裁量因子对应是否准确**
   - 每个裁量因素对应的裁量因子是否与案件事实相符
   - 不同裁量因子的选取是否有相应证据支持

3. **裁量百分值确定是否合理**
   - 裁量百分值是否在裁量表规定的区间内
   - 各裁量百分值的选取是否有充分理由

## 4.3 裁量计算正确性评查

### 4.3.1 裁量起点计算

根据《裁量基准规定》，裁量起点的计算方法为：

```
裁量起点 = 法定最低罚款数额 / 法定最高罚款数额 × 100%
```

**示例计算**：

某违法行为法定罚款幅度为10万元至100万元，则：

```
裁量起点 = 10万 / 100万 × 100% = 10%
```

### 4.3.2 裁量百分值总和计算

根据《裁量基准规定》第八条的规定：

```
裁量百分值总和 = 裁量起点对应的裁量百分值 + Σ(各裁量因素百分值)
```

**计算公式**：

```
裁量百分值总和 = 裁量起点% + Σ(裁量因素1% + 裁量因素2% + ... + 裁量因素n%)
```

### 4.3.3 最终罚款金额计算

根据《裁量基准规定》第八条的规定：

**基本公式**：

```
罚款金额 = 裁量百分值总和 × 法定最高罚款数额
```

**百分比换算公式**：

```
罚款金额 = [裁量起点% + Σ(各裁量因素百分值)] × 法定最高罚款数额
```

### 4.3.4 裁量计算示例

**示例：某超标排放水污染物案件**

假设某企业超标排放水污染物案件：
- 适用裁量表：表7-1 超标排放水污染物（直接向水体排放）
- 法定罚款幅度：10万元至100万元
- 裁量起点：20%
- 各裁量因素：
  - 超标污染物数目：1个（0%）
  - 排放污染物种类：有毒有害水污染物（12%）
  - 超标状况：超过标准100%以上不足300%（8%）
  - 日排放量：10吨以上不足100吨（3%）
  - 排放去向：Ⅲ类水体（5%）
  - 环境违法次数：1次（0%）
  - 对周边影响：无（0%）

**计算过程**：

```
裁量百分值总和 = 20% + 0% + 12% + 8% + 3% + 5% + 0% + 0%
               = 48%

罚款金额 = 48% × 100万元
         = 48万元
```

### 4.3.5 裁量计算评查要点

评查时应重点检查以下内容：

| 检查项 | 评查细则依据 | 检查要点 |
|--------|--------------|----------|
| 裁量起点计算 | 【裁量基准规定】第八条 | 裁量起点是否正确计算 |
| 裁量百分值累加 | 【裁量基准规定】第八条 | 各裁量因素百分值是否正确累加 |
| 最终金额计算 | 【裁量基准规定】第八条 | 罚款金额计算是否正确 |
| 裁量表适用 | 【裁量基准规定】第七条 | 是否正确适用专用或通用裁量表 |

## 4.4 从重/从轻/减轻裁量适用评查

### 4.4.1 从重处罚适用规则

**法律依据**：《裁量基准规定》第九条

**从重情节**：

| 序号 | 从重情节 | 说明 |
|------|----------|------|
| 1 | 拒不配合、干扰调查取证 | 在案件查处过程中拒不配合、干扰、阻挠调查取证 |
| 2 | 对执法人员等打击报复 | 对执法人员、举报人、证人进行威胁、辱骂、殴打、恐吓或打击报复 |
| 3 | 造成重大环境污染 | 违法行为造成重大环境污染 |
| 4 | 引起重大群体性事件或媒体曝光 | 违法行为引起重大群体性事件，或被主流媒体曝光且造成不良社会影响 |
| 5 | 重污染天气预警期间超标排放 | 重污染天气预警期间超标排放大气污染物 |
| 6 | 顶风作案 | 在生态环境保护督察及整改期间顶风作案 |
| 7 | 其他从重情节 | 其他符合从重处罚情形的 |

**从重处罚计算规则**：

```
从重罚款金额 = 基准罚款金额 + 增加金额

其中：
- 增加金额 ≤ 法定最高罚款数额 × 20%
- 从重罚款金额 ≤ 法定最高罚款数额
```

**特别规定**：
对于造成重大突发环境事件、重大社会影响的违法行为，经集体审议后可以按照该违法行为的法定最高罚款数额予以处罚。

### 4.4.2 从轻/减轻处罚适用规则

**法律依据**：《裁量基准规定》第十条

**从轻情节**：

| 序号 | 从轻情节 | 说明 |
|------|----------|------|
| 1 | 主动消除或减轻危害后果 | 主动消除或者减轻违法行为危害后果 |
| 2 | 受胁迫或诱骗 | 受他人胁迫或者诱骗实施违法行为 |
| 3 | 主动供述违法行为 | 主动供述生态环境部门尚未掌握的违法行为 |
| 4 | 配合查处有立功表现 | 配合生态环境部门查处违法行为有立功表现 |
| 5 | 其他从轻情节 | 法律、法规、规章规定其他应当从轻处罚情形 |

**减轻情节**：减轻处罚适用于法定最低罚款限值以下的处罚，包括：
- 选择更轻、更少的处罚种类
- 在应当并处时不并处
- 在法定最低罚款限值以下确定罚款数额

**从轻处罚计算规则**：

```
从轻罚款金额 = 基准罚款金额 - 减少金额

其中：
- 减少金额 ≤ 法定最高罚款数额 × 20%
- 从轻罚款金额 ≥ 法定最低罚款数额
```

**减轻处罚计算规则**：

```
减轻罚款金额 = 基准罚款金额 - 减少金额

其中：
- 减少金额 ≤ 法定最低罚款数额 × 50%
- 减轻罚款金额可以低于法定最低罚款数额
```

### 4.4.3 不予处罚适用规则

**法律依据**：《裁量基准规定》第十一条

**不予处罚情形**：

| 序号 | 不予处罚情形 | 说明 |
|------|--------------|------|
| 1 | 违法行为轻微并及时改正 | 违法行为轻微并及时改正，没有造成危害后果 |
| 2 | 主观无过错 | 除法律、行政法规另有规定外，当事人有证据足以证明没有主观过错 |
| 3 | 其他不予处罚情形 | 法律、法规、规章规定其他应当不予处罚情形 |
| 4 | 初次违法且危害轻微 | 当事人系初次违法且危害后果轻微并及时改正的，可以不予处罚 |

**特别要求**：
对当事人的违法行为依法不予行政处罚的，生态环境部门应当对其进行教育。

### 4.4.4 裁量情节竞合处理

**法律依据**：《裁量基准规定》第十二条

**处理规则**：
既有从轻、减轻或者不予处罚的情形，又有从重处罚情形的，应当综合衡量考虑，根据主要情节作出处罚决定。

### 4.4.5 裁量情节适用评查要点

| 检查项 | 评查细则依据 | 检查要点 |
|--------|--------------|----------|
| 从重情节认定 | 【裁量基准规定】第九条 | 是否有充分的证据证明从重情节 |
| 从重处罚计算 | 【裁量基准规定】第九条 | 从重增加金额是否超过法定最高罚款数额20% |
| 从轻情节认定 | 【裁量基准规定】第十条 | 是否有充分的证据证明从轻情节 |
| 从轻处罚计算 | 【裁量基准规定】第十条 | 从轻减少金额是否超过法定最高罚款数额20% |
| 减轻情节认定 | 【裁量基准规定】第十条 | 是否有充分的证据证明减轻情节 |
| 减轻处罚计算 | 【裁量基准规定】第十条 | 减轻减少金额是否超过法定最低罚款数额50% |
| 不予处罚认定 | 【裁量基准规定】第十一条 | 不予处罚理由是否充分、是否有教育记录 |
| 情节竞合处理 | 【裁量基准规定】第十二条 | 竞合情形是否综合衡量 |

## 5.3 证据链关联矩阵

### 5.3.1 证据与文书关联表

| 证据类型 | 主要证明内容 | 关联文书 | 评查要点 |

| 调查询问笔录 | 当事人陈述、违法过程、主观过错 | 立案审批表、案件调查报告、行政处罚决定书 | 询问内容是否与违法事实相关 |

| 送达回证 | 程序合法性 | 所有送达文书 | 是否完整、签收日期是否准确 |
