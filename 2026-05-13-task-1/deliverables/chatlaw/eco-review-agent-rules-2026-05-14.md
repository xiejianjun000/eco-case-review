### 计算公式（来源：《案卷评查细则2024版》第3页）

```
案卷得分 = 合法性评查得分（50）+ 规范性评查得分

规范性评查得分 = 50 × (对应评查项目得分之和 / 参与评查项目标准分之和) − 基本要素扣分值之和
```

## 🤖 第一章：CaseReviewAgent（合法性评查智能体）

**职责**：执行25项合法性重大问题检查，任一命中 → 触发一票否决 → 全卷得0分  
**法规依据**：《案卷评查细则（2024年版）》第一章"合法性评查标准"（第4-7页）

### 1.1 执法主体（2项）

| 编号 | 检查项目 | 判断逻辑 | 常见错误 |
|------|---------|---------|---------|
| **1** | 实施机关是否超出法定职权/管辖范围 | 检查实施机关是否具有对应违法行为的法定管辖权；是否以被委托单位名义作出处罚；分局/执法机构是否有无法定依据独立行使处罚权 | ①以被委托单位名义处罚；②无依据以分局名义作处罚决定；③决定书落款与公章单位名称不一致 |
| **2** | 执法人员是否具有行政执法资格，且不少于两人 | 核查笔录中执法证号是否在有效期内；执法人数是否≥2人 | ④执法证不在有效期；⑤笔录未记录执法证号且未附证件复印件。**注意**：笔录未记录证号但综合全卷能判断执法人员≥2人且具资质的，**不属于重大问题** |

### 1.2 违法主体（3项）

| 编号 | 检查项目 | 判断逻辑 | 常见错误 |
|------|---------|---------|---------|
| **3** | 案卷中各文书当事人名称是否一致 | 检查全卷所有文书（立案表、笔录、决定书等）的当事人名称是否完全一致；若不一致是否有合理解释 | ⑥以牌匾名称认定处罚对象且与营业执照名称不一致（如自然人姓名+工厂） |
| **4** | 处罚/强制对象是否是证据所查明的违法主体 | 核查证据所证明的违法行为主体与决定书处罚对象是否一致 | ⑦"未批先建"处罚施工单位；⑧污染源监测设备违规处罚运维单位；⑨污染防治设施问题处罚设备生产单位。**注意**：地方法规对第三方单位有规定的，需审慎判断 |
| **5** | 决定书认定的违法事实是否与证据指向一致 | 对比决定书违法事实认定与证据材料所指向事实是否吻合 | ⑩涉及非法处置危废案件中将危废认定为一般工业固废；⑪已有暗管证据的案件决定书认定为超标排污 |

### 1.3 违法事实证据（2项）

| 编号 | 检查项目 | 判断逻辑 | 常见错误 |
|------|---------|---------|---------|
| **6** | 证据是否足以证明违法行为（或不予处罚条件） | 判断全卷证据是否达到"足以证明"标准；涉采样案件需核查采样合法性证据 | ⑪涉需采样案件无采样过程合法性证据（无取样记录/笔录未载明采样情况）；证据相互矛盾且无合理解释 |
| **7** | 当事人是否有无主观过错证据但仍予以处罚 | 检查当事人是否提出无主观过错证据，若提出，核查是否经核实；核实后是否有正当理由仍予处罚 | 无主观过错但强行处罚（违反《行政处罚法》第33条第2款）|

### 1.4 法律适用（5项）

| 编号 | 检查项目 | 判断逻辑 | 常见错误 |
|------|---------|---------|---------|
| **8** | 决定书违法事实描述是否与适用法律规定相符 | 比对违法行为描述与引用条款的构成要件是否对应 | 违法行为描述与条款构成要件不匹配 |
| **9** | 决定书是否有法律/法规/规章依据 | 检查决定书处罚依据是否有明确法律条文支撑 | ⑪对未处于生产状态的建设项目可能产生污染排放的行为实施查封（无依据） |
| **10** | 法律条款是否准确引用 | 逐条核对引用条款编号、内容与现行法律是否吻合；核查是否遵循"从旧兼从轻"原则 | ⑪建设项目违法中违反从旧兼从轻原则，未适用违法行为发生时的法律规定 |
| **11** | 兜底条款/等外条款适用是否有法定依据 | 核查是否有相应法律依据支撑兜底条款适用；如《查封扣押办法》第4条第1款第6项须有法律依据 | 无相关法律依据适用兜底条款 |
| **12** | 处罚/强制决定是否在法定幅度内 | 核查罚款金额是否在法定最低至最高区间；是否有因当事人陈述申辩而加重处罚；是否无裁量基准依据超最低限减轻；查封扣押标的物是否与违法行为有关 | ⑪因当事人陈述申辩而加重处罚；⑪无依据超出下限减轻处罚；⑬查封扣押无关设施。**注意**：裁量不当或额度计算错误纳入**规范性评查**，不属于一票否决 |

### 1.5 执法程序（13项）

#### 告知权利组（3项）

| 编号 | 检查项目 | 判断逻辑 |
|------|---------|---------|
| **13** | 处罚前是否告知程序性权利（陈述/申辩/听证） | 核查是否有告知书；是否在法定期限前已给予足够时间（5日、7日均按自然日计）；是否有送达证明；是否告知了监测/检测/鉴定结果。**注意**：不予行政处罚案件作出决定前未告知，暂不列为合法性问题 |
| **14** | 是否拒绝听取陈述申辩/未对陈述申辩进行复核 | 当事人提出回避申请是否作出决定；是否拒绝陈述申辩；是否对申辩内容进行复核；要求听证是否举行 |
| **15** | 查封/扣押是否当场告知权利 | 核查是否制作了查封/扣押现场笔录；是否告知理由、依据、权利、救济途径；是否记录陈述申辩。**注意**：紧急情况可在现场检查笔录中告知 |

#### 集体讨论组（2项）

| 编号 | 检查项目 | 判断逻辑 |
|------|---------|---------|
| **16** | 情节复杂/重大违法行为是否经集体讨论 | 核查是否制作了集体讨论记录；当事人进行陈述申辩或要求听证后是否再次组织集体讨论。**注意**：不属于集体讨论范围的案件不纳入此项 |
| **17** | 调查人员是否参与了表决 | 检查集体讨论记录中参与表决人员是否包括调查人员 |

#### 法制审核组（1项）

| 编号 | 检查项目 | 判断逻辑 |
|------|---------|---------|
| **18** | 重大执法决定是否经法制审核 | 核查是否有法制审核表且审核通过；通过陈述申辩/听证获得新证据后是否再次审核。**注意**：不属于法制审核范围的案件不纳入此项 |

#### 其他程序组（4项）

| 编号 | 检查项目 | 判断逻辑 |
|------|---------|---------|
| **19** | 是否超过法定追责期限 | 计算违法行为发现日与处罚决定日之间的时间跨度，核查是否超出法定追责期限 |
| **20** | 调查人员是否同时担任审查人员 | 核查法制审核表、集体讨论记录中的审查人员是否与调查取证人员重合 |
| **21** | 按日连续处罚：有无证据证明已责令改正 | 按日连续处罚决定前，核查是否有责令改正决定书及送达证明 |
| **22** | 按日连续处罚：是否在规定时间内实施复查 | 核查复查记录时间是否符合法定要求（责令改正后需在规定期限内复查） |
| **23** | 按日连续处罚：处罚决定是否早于原处罚决定 | 核对按日连续处罚决定书日期是否晚于原行政处罚决定书作出/送达日期 |
| **24** | 查封/扣押是否超期未解除 | 核算查封/扣押期限（一般不超过30日），是否有审批延期；超期是否作出解除决定 |

### 1.6 一票否决触发逻辑（伪代码）

```python
def case_review_check(case_data: CaseData) -> CaseReviewResult:
    """
    CaseReviewAgent 核心逻辑
    来源：《案卷评查细则（2024版）》第一章，第4-7页
    """
    critical_issues = []
    
    # 1. 执法主体（2项）
    if check_authority_out_of_scope(case_data):           # 第1项
        critical_issues.append("执法主体超权限/管辖")
    if not check_executor_qualification(case_data):       # 第2项
        critical_issues.append("执法人员资质/人数不符")
    
    # 2. 违法主体（3项）
    if check_party_name_inconsistent(case_data):          # 第3项
        critical_issues.append("当事人名称不一致且无合理解释")
    if check_party_mismatch_evidence(case_data):          # 第4项
        critical_issues.append("处罚对象与证据指向主体不符")
    if check_fact_mismatch_evidence(case_data):           # 第5项
        critical_issues.append("决定书事实认定与证据材料不符")
    
    # 3. 违法事实证据（2项）
    if not check_evidence_sufficient(case_data):          # 第6项
        critical_issues.append("证据不足即予处罚")
    if check_no_fault_punished(case_data):                # 第7项
        critical_issues.append("无主观过错证据仍予处罚")
    
    # 4. 法律适用（5项）
    if check_law_mismatch_fact(case_data):                # 第8项
        critical_issues.append("违法事实与法律条款不符")
    if not check_legal_basis_exists(case_data):           # 第9项
        critical_issues.append("决定无法律依据")
    if not check_law_article_accurate(case_data):         # 第10项
        critical_issues.append("法律条款引用不准确（含从旧兼从轻）")
    if check_catchall_without_basis(case_data):           # 第11项
        critical_issues.append("兜底条款适用无依据")
    if check_penalty_out_of_range(case_data):             # 第12项
        critical_issues.append("处罚超出法定幅度")
    
    # 5. 执法程序（13项）
    if not check_rights_informed(case_data):              # 第13项
        critical_issues.append("未告知陈述申辩听证权利")
    if check_objection_refused(case_data):                # 第14项
        critical_issues.append("拒绝听取陈述申辩/未复核")
    if not check_seizure_rights_informed(case_data):      # 第15项
        critical_issues.append("查封扣押未告知权利")
    if not check_collective_discussion(case_data):        # 第16项
        critical_issues.append("应集体讨论未讨论")
    if check_investigator_in_vote(case_data):             # 第17项
        critical_issues.append("调查人员参与表决")
    if not check_legal_review_done(case_data):            # 第18项
        critical_issues.append("应法制审核未审核")
    if check_over_accountability_period(case_data):       # 第19项
        critical_issues.append("超过法定追责期限")
    if check_investigator_is_reviewer(case_data):         # 第20项
        critical_issues.append("调查人员同时担任审查人员")
    if not check_daily_penalty_correction_order(case_data):  # 第21项
        critical_issues.append("按日连续处罚无责令改正证据")
    if not check_daily_penalty_reinspection(case_data):   # 第22项
        critical_issues.append("按日连续处罚未按期复查")
    if check_daily_penalty_order_date(case_data):         # 第23项
        critical_issues.append("按日连续处罚决定早于原处罚决定")
    if check_seizure_overdue(case_data):                  # 第24项
        critical_issues.append("查封扣押超期未解除")
    
    if critical_issues:
        return CaseReviewResult(
            score=0,
            triggered_veto=True,
            issues=critical_issues,
            reason="一票否决：" + "；".join(critical_issues)
        )
    else:
        return CaseReviewResult(
            score=50,
            triggered_veto=False,
            issues=[],
            reason="合法性评查通过，得50分"
        )
```

## 🤖 第二章：NormativeScoringAgent（规范性评分智能体）

**职责**：执行两部分规范性评查——卷面基本要素扣分（20分）+ 各类型文书逐项得分  
**法规依据**：《案卷评查细则（2024年版）》第二章（第8-36页）

### 2.1 卷面基本要素评查项（20分，扣分制）

> **规则**：任一文书存在以下缺少基本要素情形，均扣除该要素对应分数（可重复扣，上限不超过20分）

#### A. 各类文书基本要素（10分）

| 编号 | 要素项目 | 扣分值 | 评查要点 |
|------|---------|--------|---------|
| A1 | 生态环境主管部门名称、文书名称、发文字号、印章、日期；负责人审批意见及签名、日期 | 3分 | 六项缺一扣3分；结合文书实际情况 |
| A2 | 承办人意见及签名、日期；承办机构负责人审批意见及签名、日期 | 2分 | |
| A3 | 当事人基本信息（当事人名称或姓名、地址、统一社会信用代码或身份证件号） | 2分 | |
| A4 | 送达回证 | 2分 | |
| A5 | 卷面规范（一案一卷、统一规范卷皮、目录填写规范、材料排列有序、有页号） | 1分 | |

#### B. 现场检查（勘察）/调查询问笔录基本要素（10分）

| 编号 | 要素项目 | 扣分值 | 评查要点 |
|------|---------|--------|---------|
| B1 | 现场检查/询问的起止时间、地点 | 1分 | |
| B2 | 检查人/询问人、记录人基本信息 | 1分 | |
| B3 | 被检查人/被询问人基本信息及身份 | 1分 | |

### 2.3 规范性评分计算逻辑（伪代码）

```python
def normative_scoring(case_data: CaseData) -> NormativeResult:
    """
    NormativeScoringAgent 核心逻辑
    来源：《案卷评查细则（2024版）》第二章，第8-36页
    """
    # === 第一步：卷面基本要素扣分（20分）===
    basic_deductions = 0
    
    # A组：各类文书基本要素（最多扣10分）
    if check_missing_header_elements(case_data):   basic_deductions += 3  # A1
    if check_missing_handler_sig(case_data):       basic_deductions += 2  # A2
    if check_missing_party_info(case_data):        basic_deductions += 2  # A3
    if check_missing_service_receipt(case_data):   basic_deductions += 2  # A4
    if check_poor_file_format(case_data):          basic_deductions += 1  # A5
    
    # B组：现场/询问笔录要素（最多扣10分）
    if check_missing_time_place(case_data):        basic_deductions += 1.0  # B1
    if check_missing_officer_info(case_data):      basic_deductions += 1.0  # B2
    if check_missing_party_id(case_data):          basic_deductions += 1.0  # B3
    if check_missing_badge_show(case_data):        basic_deductions += 1.5  # B4
    if check_missing_rights_inform(case_data):     basic_deductions += 1.5  # B5
    if check_missing_page_sig(case_data):          basic_deductions += 1.0  # B6
    if check_missing_officer_sig(case_data):       basic_deductions += 1.0  # B7
    if check_blank_lines(case_data):               basic_deductions += 1.0  # B8
    if check_correction_sig(case_data):            basic_deductions += 1.0  # B9
    
    basic_deductions = min(basic_deductions, 20)   # 上限20分
    
    # === 第二步：各类型文书得分 ===
    case_type = case_data.case_type  # 案卷类型
    doc_scores = calculate_doc_scores_by_type(case_data, case_type)
    doc_max = get_max_scores_by_type(case_type)  # 参与评查项目标准分之和
    
    # === 第三步：规范性总分计算 ===
    normative_score = 50 * (doc_scores / doc_max) - basic_deductions
    normative_score = max(0, normative_score)   # 不低于0
    
    # === 第四步：加分项（仅移送拘留/犯罪类型）===
    bonus = 0
    if case_type in ["移送拘留", "移送犯罪"]:
        if check_police_decision(case_data):
            bonus = 15
    
    return NormativeResult(
        basic_deductions=basic_deductions,
        doc_scores=doc_scores,
        doc_max=doc_max,
        normative_score=normative_score,
        bonus=bonus,
        detail=generate_detail_report(case_data)
    )
```

## 🤖 第三章：LegalDiscretionAgent（裁量计算智能体）

**职责**：依据《湖南省生态环境保护行政处罚裁量权基准规定（2021版）》，计算裁量百分值、校验罚款金额合法性  
**法规依据**：裁量基准第1-17条 + 附表《湖南省生态环境违法行为行政处罚罚款金额裁量表》

### 3.1 核心裁量公式（第5条、第8条）

```
罚款金额 = 裁量百分值总和 × 法定最高罚款数额（或倍数）

裁量百分值总和 = 裁量起点百分值 + 各裁量因素百分值之和
```

### 3.2 裁量操作步骤（第8条）

1. **选择裁量表**：有专用裁量表→用专用；无→用通用
2. **选定裁量起点**：违法行为法定最低罚款额对应的百分值
3. **确定各因素百分值**：逐一确定6项裁量因素的百分值，累加
4. **计算基准罚款**：总百分值 × 法定最高罚款额（或倍数）
5. **集体审议确认**：基准金额经集体审议后确定最终罚款金额

### 3.3 六项裁量因素（第6条）

| 序号 | 裁量因素 |
|------|---------|
| ① | 违法行为造成的环境污染、生态破坏程度及社会影响 |
| ② | 当事人的主观过错程度 |
| ③ | 违法行为的具体方式或手段 |
| ④ | 违法行为危害的具体对象 |
| ⑤ | 当事人的环境违法行为次数（两年内，含本次） |
| ⑥ | 当事人改正违法行为的态度和所采取的改正措施及效果 |

### 3.4 从重处罚情形（第9条）

| 情形 | 裁量规则 |
|------|---------|
| ①拒不配合/干扰调查，威胁辱骂殴打执法人员/举报人/证人 | 增加不超过法定最高罚款20%，且从重后金额不得超法定最高 |
| ②违法行为造成重大环境污染 | 同上 |
| ③引起重大群体性事件/被主流媒体曝光造成不良社会影响 | 同上 |
| ④重污染天气预警期间超标排放大气污染物 | 同上 |
| ⑤生态环境保护督察及整改期间顶风作案 | 同上 |
| **特别情形**：造成重大突发环境事件、重大社会影响 | 经集体审议后可按该违法行为**法定最高罚款额**处罚 |

### 3.5 从轻/减轻/不予处罚（第10-11条）

| 类型 | 条件 | 裁量规则 |
|------|------|---------|
| **从轻处罚** | ①主动消除减轻危害后果；②受胁迫/诱骗；③主动供述未掌握的违法；④配合查处有立功表现 | 减少**不超过法定最高罚款20%**，且不低于法定最低罚款 |
| **减轻处罚** | 符合减轻条件 | 在裁定金额基础上减少，一般**不超过法定最低罚款50%** |
| **不予处罚** | ①违法行为轻微且及时改正无危害后果；②无主观过错（有证据）；③法律规定其他情形；④初次违法且危害后果轻微及时改正 | 不予处罚，但需对当事人进行教育 |

### 3.7 裁量校验逻辑（伪代码）

```python
def legal_discretion_check(case_data: CaseData) -> DiscretionResult:
    """
    LegalDiscretionAgent 核心逻辑
    来源：《湖南省裁量基准规定（2021版）》第1-17条及附表
    """
    # 1. 识别违法行为类型，选择裁量表
    violation_type = identify_violation_type(case_data)
    table = select_discretion_table(violation_type)  # 有专用用专用，无用通用
    
    # 2. 确定裁量起点
    base_percentage = get_base_percentage(table, violation_type)
    
    # 3. 计算六项裁量因素百分值
    factor_percentages = calculate_factor_percentages(case_data, table)
    
    # 4. 计算总百分值
    total_percentage = base_percentage + sum(factor_percentages.values())
    
    # 5. 计算基准罚款
    max_penalty = get_max_penalty(violation_type, case_data)
    base_fine = total_percentage * max_penalty
    
    # 6. 从重/从轻/减轻调整
    if has_aggravating_factors(case_data):  # 从重（第9条）
        additional = calculate_aggravating_amount(base_fine, max_penalty)
        final_fine = base_fine + additional
        final_fine = min(final_fine, max_penalty)  # 不超法定最高
    elif has_mitigating_factors(case_data):  # 从轻（第10条）
        reduction = calculate_mitigating_amount(base_fine, max_penalty)
        final_fine = base_fine - reduction
        min_penalty = get_min_penalty(violation_type, case_data)
        final_fine = max(final_fine, min_penalty)  # 不低于法定最低
    elif has_reduction_factors(case_data):  # 减轻（第10条）
        min_penalty = get_min_penalty(violation_type, case_data)
        final_fine = max(base_fine * 0.5, 0)  # 一般不超过法定最低50%
    else:
        final_fine = base_fine
    
    # 7. 不予处罚检查（第11条）
    if check_no_penalty_conditions(case_data):
        return DiscretionResult(
            penalty=0,
            reason="符合不予处罚条件",
            education_required=True
        )
    
    # 8. 校验案卷罚款是否符合裁量计算结果
    actual_fine = extract_penalty_from_decision(case_data)
    deviation = abs(actual_fine - final_fine) / final_fine if final_fine > 0 else 0
    
    return DiscretionResult(
        calculated_fine=final_fine,
        actual_fine=actual_fine,
        is_compliant=(deviation < 0.05),  # 允许5%误差
        violation_type=violation_type,
        table_used=table,
        base_percentage=base_percentage,
        factor_percentages=factor_percentages,
        total_percentage=total_percentage,
        deviation_ratio=deviation,
        requires_collective_review=True  # 第8条第4款
    )
```

## 🤖 第四章：EvidenceChainAgent（证据链分析智能体）

**职责**：专项分析证据材料完整性、证据之间的逻辑一致性、证据链完整性  
**法规依据**：《案卷评查细则（2024版）》合法性第6-7项 + 规范性各类文书证据评分细则

### 4.1 证据材料分类标准

```
证据体系（来源：《案卷评查细则》文书评分细则）
├── 书证
│   ├── 企业营业执照（或自然人身份证件）
│   ├── 环评文件/竣工验收报告
│   ├── 排污许可证
│   └── 其他根据案情需要的书证
├── 视听资料
│   ├── 现场照片/录像（需注明：证明对象/拍摄时间地点/拍摄人/证明内容）
│   └── 采样视频等
├── 监测/检测/鉴定报告
│   ├── 机构全称 + 资质认定标志 + 字号
│   ├── 委托单位 + 项目名称
│   ├── 采样时间 + 分析结果
│   └── 签名/印章
├── 现场检查（勘察）笔录
└── 证人证言（需有证人基本情况、签名、日期）
```

### 4.2 证据链完整性检查规则

| 检查维度 | 检查内容 | 合法性影响 |
|---------|---------|---------|
| **证据充分性** | 证据是否足以证明违法行为 | 不足→**第6项重大问题** |
| **证据一致性** | 不同证据之间是否互相矛盾 | 矛盾无解释→**第6项重大问题** |
| **主观过错** | 是否有无主观过错证据 | 有则未经核实仍处罚→**第7项重大问题** |
| **采样合法性** | 需采样案件是否有采样合法性证据（取样记录/笔录记载采样情况） | 缺失→**第6项重大问题** |
| **事实一致性** | 决定书违法事实认定与证据指向是否一致 | 不一致→**第5项重大问题** |

### 4.3 规范性证据评分细则（各案卷类型通用）

```python
def evidence_scoring(case_data: CaseData) -> EvidenceScore:
    """
    证据材料规范性评分（NormativeScoringAgent的子模块）
    """
    score = 0
    
    # 书证部分（5分）
    if has_business_license_or_id(case_data):         score += 3  # 营业执照等
    if has_correct_copy_notation(case_data):          score += 1  # "经核对原件无误"
    if has_collection_info(case_data):                score += 2  # 调取时间/提供人/签名（注：移送犯罪类型各项分值更高）
    
    # 视听资料
    if has_photo_video_annotation(case_data):         score += 1  # 注明证明对象等
    
    # 证人证言（如有）
    if has_witness_statement_complete(case_data):     score += 1  # 证人信息/签名/日期
    
    # 证据链逻辑检查（影响调查报告评分）
    if evidence_chain_consistent(case_data):          evidence_chain_ok = True
    
    return EvidenceScore(score=score, chain_ok=evidence_chain_ok)
```

```python
def identify_case_type(case_documents: list) -> str:
    """
    根据文书组合识别案卷类型
    来源：文书范本说明第3页
    """
    doc_names = {doc.name for doc in case_documents}
    
    if "按日连续处罚决定书" in doc_names or "再次责令改正违法行为决定书" in doc_names:
        return "按日连续处罚"
    elif "查封/扣押决定书" in doc_names or "查封/扣押审批表" in doc_names:
        return "查封/扣押"
    elif "涉嫌环境违法适用行政拘留处罚案件移送审批表" in doc_names:
        return "移送拘留"
    elif "涉嫌环境犯罪案件移送审批表" in doc_names:
        return "移送犯罪"
    elif "不予行政处罚决定书" in doc_names:
        return "不予行政处罚"
    elif "行政处罚决定书" in doc_names:
        return "一般行政处罚"
    else:
        return "待人工确认"
```
