## 3. V4规范核心要求

### 3.1 50分制评分体系

| 评估维度 | 最高分值 | 说明 |
|----------|----------|------|
| 合法性评估 | 50分 | 基础分值，直接采用 |
| 规范性评估 | 50分 | 按章扣分，上限50 |
| **综合得分** | **100分** | 合法性 + 规范性 |

### 3.2 一票否决机制

满足以下任一条件，直接判定为**不合格**：

1. 合法性评估得分 = 0
2. 规范性评估得分 < 18
3. 存在重大合规缺陷

### 3.3 9+1章节结构

```
封面
├─1. 基本信息
├─2. 合法性评估
├─3. 规范性评估
├─4. 综合评分
├─5. 结论与建议
└─附件（如有）
```

### 3.4 评分公式

```
综合得分 = 合法性评估得分 + 规范性评估得分

等级划分：
- 优秀：≥90分
- 良好：75-89分
- 合格：60-74分
- 不合格：<60分 或 触发一票否决
```
