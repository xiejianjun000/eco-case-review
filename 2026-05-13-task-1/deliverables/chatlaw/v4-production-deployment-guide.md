## 三、容器化部署方案

### 3.1 Dockerfile特性

| 特性 | 实现 |
|------|------|
| 多阶段构建 | builder + runtime |
| 非root用户 | appuser |
| 健康检查 | /health接口 |
| 优雅停机 | dumb-init + graceful |
| 安全扫描 | Trivy配置 |
| 镜像大小 | <500MB |

### 3.2 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| OCR_ENGINE | local | OCR引擎 |
| MAX_PDF_SIZE | 50 | 最大PDF大小(MB) |
| MAX_PAGES | 500 | 最大页数 |
| LOG_LEVEL | INFO | 日志级别 |
| REDIS_URL | redis://... | 缓存地址 |
| SECRET_KEY | change-me | 密钥(生产必改) |

### 3.3 资源限制

```yaml
resources:
  limits:
    memory: 2Gi
    cpu: 2000m
  requests:
    memory: 512Mi
    cpu: 500m
```

### 3.4 部署命令

```bash
# 开发环境
docker compose up -d

# 生产环境
docker compose --profile prod up -d

# 查看日志
docker compose logs -f v4-review

# 缩放实例
docker compose up -d --scale v4-review=3
```
