## 二、合法性评查——重大缺陷分析（4项）

### 缺陷2.1：评分制与V4规范严重不符

**V4规范要求**（CaseReviewAgent第3段Context + ReportGenerationAgent第6段Output Format）：

```
合法性评查得分 = 50分（通过）或 0分（一票否决）
```

**当前系统输出**（以TC002为例）：
```
| 合法性评查 | 4/4 | 一票否决制 | ✓ |
```

**问题**：
- 当前系统使用**4分制**（满分4分），V4规范要求**50分制**（满分50分）或**0分制**（一票否决0分）
- 4分制无法体现V4规范中"50分"的合法性权重，与综合得分计算公式严重脱节
- 等级评定标准"不合格<60分"中，60分包含合法性50分+规范性50分的双重权重，4分制无法对应

**证据**：
| 案卷 | 当前合法性得分 | V4规范要求 |
|------|-------------|-----------|
| TC002 | 4/4 | 50分或0分 |
| TC003 | 4/4 | 50分或0分 |
| TC004 | 4/4 | 50分或0分 |
| TC005 | 4/4 | 50分或0分 |
| TC006 | 2/4 | 50分或0分 |
| TC007 | 2/4 | 50分或0分 |

---

### 缺陷2.2：TC005一票否决机制失效（最严重问题）

**V4规范要求**（CaseReviewAgent第4段Constraints）：

> "一票否决刚性约束：存在以下任一重大问题即评定为0分，不得以任何理由变通：……未保障当事人陈述申辩权……"

**TC005发现的问题**：
```
### 1. 合法性评查
**评分**: 4/4

**发现问题**:
- 【评查细则】一.5：未经法定程序批准擅自立案
- 【评查细则】一.10：未告知当事人陈述申辩权利
```

**JSON数据**（批量评查结果.json）：
```json
{
  "id": "TC005",
  "legality_score": 4,
  "final_score": 60.5,
  "final_grade": "合格",
  "final_pass": true,
  "veto_triggered": false  ← 一票否决未触发！
}
```

**问题**：
- 发现两项重大程序违法（擅自立案+未告知陈述申辩权），按V4规范应**直接评为0分**
- 但`veto_triggered: false`，`final_pass: true`，`final_grade: "合格"`
- 合法性评分仍为4/4，与一票否决制逻辑矛盾
- 结论：**一票否决机制在TC005中完全失效**

**V4规范溯源**（评查细则第14项）：
> "作出行政处罚决定前未告知程序性权利（陈述、申辩、听证等）……没有证据证明已经依法送达了告知书……"

---

### 缺陷2.3：TC006/TC007合法性问题未触发一票否决

**TC006发现的问题**：
```
【评查细则】一.7：超出法定办理时限
```

**TC007发现的问题**：
```
【评查细则】一.5：未经法定程序批准擅自立案
【评查细则】一.7：超出法定办理时限
```

**JSON数据**：
```json
// TC006
{ "legality_score": 2, "veto_triggered": false, "final_pass": false }

// TC007
{ "legality_score": 2, "veto_triggered": false, "final_pass": false }
```

**问题**：
- TC006/TC007的`veto_triggered`均为`false`，说明一票否决未触发
- 但两者均`final_pass: false`且等级为"不合格"
- 2/4的合法性评分与V4规范的"50分或0分"评分制不匹配

**V4规范溯源**（评查细则第17项）：
> "对情节复杂或者重大违法行为给予行政处罚前，未经行政机关负责人集体讨论决定，或未制作集体讨论记录。"

擅自立案（序号5）和超办理时限（序号7）的定性需结合案情综合判断，但当前系统采用"4分制扣分"而非"0/50分判定"，评分逻辑与V4规范存在本质差异。

### 缺陷2.4：合法性得分与综合得分计算逻辑断裂

**V4规范要求**（ReportGenerationAgent第3段Context）：

```
案卷得分 = 合法性评查得分(50) + 规范性评查得分
规范性评查得分 = 50 × 文书评查项得分之和 / 参与评查项目标准分之和 - 基本要素扣分值之和
```

**当前系统TC002的计算**：
```
合法性得分: 4/4
规范性得分: 3.2/4
综合得分: 62.8/100
```

**问题**：
- V4规范的"50分"包含在"≤100分"的总分体系中
- 当前4分制无法映射到50分权重，导致综合得分62.8无法用V4公式验证
- TC002综合得分62.8分，但无法确认其计算过程是否符合V4公式

### 缺陷3.2：缺失比例换算逻辑

**V4规范要求**（v4-normative-scoring-rules.md第一章第1.3节）：

```
规范性评查得分 = 50 × (文书评查项得分之和 / 参与评查项目标准分之和) - 基本要素扣分值之和
```

**当前系统**：无此计算逻辑，所有案卷均显示"3.1/4"~"3.5/4"范围，分数集中度过高，无法体现不同案卷的实质差异。

---

### 缺陷3.3：14项卷面基本要素未逐项检查

**V4规范要求**（v4-normative-scoring-rules.md第二章）：

评查细则二（一）共14项卷面基本要素：
- 各类文书基本要素（10分）：生态环境主管部门名称/文书名称/发文字号/印章/日期（3分）、负责人审批意见及签名日期（2分）、当事人基本信息（2分）、送达回证（2分）、卷面规范（1分）
- 笔录基本要素（10分）：检查/询问起止时间地点（1分）、检查人/询问人/记录人信息（1分）、被检查人/被询问人信息（1分）、出示执法证件及表明身份（1.5分）、告知权利（1.5分）、逐页签名及审阅意见（1分）、末页签名（1分）、无空行标注（1分）、修改处签名（1分）

**当前系统**：仅笼统提及"法制审核"、"处罚决定书日期"、"印章"三项，未逐项检查14项基本要素。

## 四、综合评分计算——缺陷分析（2项）

### 缺陷4.1：综合得分计算公式不透明

**V4规范要求**（ReportGenerationAgent第6段Output Format第7.1节）：

```
### 7.1 综合得分计算
| 项目 | 得分 |
|------|------|
| 合法性评查得分 | 50分（或0分） |
| 规范性评查得分 | XX分 |
| **综合得分** | **XX分** |
```

**当前系统**（TC002）：
```
| 合法性评查 | 4/4 | 一票否决制 | ✓ |
| 规范性评查 | 3.2/4 | 比例换算制 | ✓ |
| 综合评分 | 62.8/100 | 综合评定 | ✓ |
```

**问题**：
- V4规范：综合得分 = 合法性(50分) + 规范性(≤50分) = 0~100分
- 当前4分制如何映射到50分权重？3.2/4是否等于40分（=50×3.2/4）？如果是，则TC002的规范性得分=40分，合法性=50分，综合=90分，与62.8分不符
- 计算逻辑不透明，无法验证

**验证TC002**：
```
假设：规范性得分 = 50 × (3.2/4) = 40分
V4规范：综合得分 = 50(合法性) + 40(规范性) = 90分
当前系统：综合得分 = 62.8分
→ 差值27.2分，计算逻辑不明
```

---

| 评定等级 | 得分区间 | 说明 |

| 优秀 | ≥90分 | 案卷质量优秀，可作为示范 |
| 良好 | 80-89分 | 案卷质量良好，存在轻微瑕疵 |
| 合格 | 60-79分 | 案卷质量基本合格，存在一定问题 |
| 不合格 | <60分或一票否决 | 案卷质量不合格，需重大整改 |

**TC005矛盾分析**：
```
发现问题：
- 【评查细则】一.5：未经法定程序批准擅自立案
- 【评查细则】一.10：未告知当事人陈述申辩权利
- veto_triggered: false
- final_pass: true
- final_grade: "合格"
```

**问题**：
- TC005发现两项重大程序违法（违反《行政处罚法》第44-45条），按V4规范应一票否决评为0分
- 但系统评定为"合格"（60.5分），存在严重的逻辑矛盾
- V4规范明确"不合格：<60分或一票否决"，重大程序违法属于"一票否决"，而非"60.5分合格"

### 缺陷5.2：裁量百分值加总与湖南省裁量基准不符

**湖南省裁量基准规定（2021版）**：

```
罚款金额 = [裁量起点% + Σ(各裁量因素百分值)] × 法定最高罚款数额
裁量起点 = 法定最低罚款数额 / 法定最高罚款数额 × 100%
```

**当前系统TC002**：
```
裁量起点: 10.0%
裁量因素: +15.0%（违反重污染天气应急响应）
裁量百分值: 25.0%
计算罚款: 250,000元（法定最高罚款100万元）
```

**问题**：
- 缺少**裁量百分值来源说明**（哪个裁量表？专用表还是通用表？）
- 缺少**法定最低罚款数额**和**法定最高罚款数额**的标注
- 缺少从重/从轻/减轻情节的专项分析
- TC006/TC007显示裁量计算罚款(400,000/250,000元)与案卷记载(50,000/29,000元)差异巨大，缺少合理性说明
